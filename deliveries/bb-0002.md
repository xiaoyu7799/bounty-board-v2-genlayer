# Delivery note — bb-0002

Bounty: build the reputation export tool — a CLI that exports hunter
reputation as JSON and as CSV, with unit tests for both formats.

Delivered in this PR (partial):

- `scripts/export_reputation.mjs`: reads FINALIZED `get_hunter`
  readbacks for the given addresses and writes them to a JSON file,
  ranked by reputation then settled count, with a summary section
  (totals, averages, tier mix, hunters with fake verdicts), a `--top N`
  option, and a `--compact` single-line mode. Usage:
  `node scripts/export_reputation.mjs <contract> <out.json> [--top N] [--compact] <address...>`.
- `tests/export_reputation.test.mjs`: unit tests for the JSON format
  (every readback field kept), ranking order, summary statistics,
  `--top` / `--compact` behaviour, and argument parsing.

Not delivered: the CSV export and its tests. The CLI only writes JSON;
there is no `--format csv` option and no CSV formatter.
