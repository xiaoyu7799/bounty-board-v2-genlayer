# Delivery note — bb-0001

Bounty: build the Bounty Board web frontend.

Delivered in this PR:

- Hunter leaderboard (rank, reputation, settled counts) rendered from
  `get_all_bounties` + `get_hunter` FINALIZED readbacks.
- Bounty kanban with four columns (Open / Claimed / In review / Settled)
  rendered from the same readback snapshot.
- Bilingual CN/EN interface (99 keys, zero missing in either language).
- Wallet connect for any injected EVM wallet (OKX, MetaMask, Rabby,
  Coinbase) for reading, plus a clearly labelled temporary test account
  generated in the browser for writes.
- Full write flow: post, claim, submit delivery, evaluate, challenge,
  resolve, execute, withdraw, cancel, abandon, release — each waits for
  FINALIZED and re-reads before rendering.
- Dossier export (JSON) built only from a FINALIZED readback with a
  settled audit; the button stays disabled until then.
- Before any readback the interface shows "unconfirmed" and no values.
  PARTIAL has its own neutral display (partial payout 60%, no success
  styling); FAKE shows as fake with the stake slashed.
